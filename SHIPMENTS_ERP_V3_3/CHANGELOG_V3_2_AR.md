# سجل تغييرات SHIPMENTS ERP V3.2

- إضافة دفتر عهدة مستقل للمندوبين مع حركات مدين/دائن ورصيد متحرك.
- إضافة شاشة تسجيل الحركات، اختيار المندوب، إضافة مرجع مصدر وسبب إلزامي، وعرض دفتر الحركة وتصديره CSV.
- إضافة قيود عكسية مستقلة بدل تعديل أو حذف الحركة الأصلية.
- إضافة API محلي تجريبي باستخدام SQLite لإضافة القيود وقراءتها وعكسها.
- إضافة قيود قاعدة بيانات تمنع UPDATE وDELETE على دفتر SQLite، وإضافة تصميم PostgreSQL مع Trigger وفهرس لمنع تكرار عكس الحركة.
- إضافة اختبارات للرصيد المتحرك، رفض التوريد الزائد، القيد العكسي، ومنع التعديل والحذف.
- لم يتم ربط قاعدة سحابية أو تشغيل اعتماد مالي حقيقي. واجهة HTML لا تزال مستقلة وتخزن سجلها في المتصفح.

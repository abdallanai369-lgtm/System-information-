# SHIPMENTS ERP V3.3

- إضافة تسجيل الدخول بكلمات مرور مخزنة باستخدام PBKDF2-HMAC-SHA256 ورموز وصول HMAC موقعة.
- إضافة 6 أدوار وصلاحيات منفصلة.
- تقييد مستخدمي الفروع بفرعهم، وحساب المندوب بدفتره المرتبط.
- إضافة إنشاء المستخدمين بواسطة مدير النظام فقط.
- إضافة سجل مراجعة للأحداث المالية وتسجيل الدخول.
- حماية دفتر العهدة وسجل المراجعة من UPDATE/DELETE في SQLite التجريبي.
- إضافة مخطط PostgreSQL للمستخدمين وسجل المراجعة.
- توثيق API وإعدادات الأسرار.

## حدود معلنة
لا توجد قاعدة PostgreSQL سحابية متصلة، ولا يزال HTML يعمل محليًا دون API. V3.3 يضيف طبقة API تجريبية للمصادقة والصلاحيات ولا يمثل نشرًا إنتاجيًا أو اعتمادًا ماليًا.

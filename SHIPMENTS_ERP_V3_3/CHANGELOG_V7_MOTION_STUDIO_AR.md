# SHIPMENTS ERP V7 – Motion Studio

- تطوير طبقات 3D بظلال متعددة وإحساس عمق واقعي للكروت والمؤشرات والفواتير.
- إضافة حركة إضاءة محيطية هادئة وأشكال ضوئية عائمة بالخلفية.
- انتقالات دخول مستقلة عند تبديل الصفحات مع ظهور متدرج للعناصر.
- تأثير ميلان 3D بسيط يتبع حركة المؤشر على الأجهزة المكتبية.
- تأثير لمعان للأزرار والجداول ومؤشرات التقدم، مع Ripple عند الضغط.
- الحفاظ على دعم اللمس وتقليل الحركة حسب إعدادات إمكانية الوصول.
- لا تغيير على منطق البيانات أو API أو قاعدة البيانات.

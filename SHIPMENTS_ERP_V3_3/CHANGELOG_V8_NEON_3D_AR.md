# SHIPMENTS ERP V8 — Neon 3D Reference Design

- اعتماد الهوية البصرية المستوحاة من الصور المرجعية: أسود/كحلي عميق مع أزرق كهربائي متوهج ولمسات سماوي وبنفسجي وأخضر.
- تحويل البطاقات ولوحات البيانات والجداول إلى أسطح زجاجية داكنة بحدود مضيئة وعمق ثلاثي الأبعاد.
- إضافة حركة ضوئية متدرجة على حواف البطاقات، وانتقالات دخول الصفحات، وتفاعل ميلان أقوى مع مؤشر الماوس.
- تطوير الأزرار وحقول الإدخال والجداول والفاتورة بنفس الهوية البصرية.
- الحفاظ على الصفحات المستقلة والوظائف الحالية والواجهة العربية RTL.
- دعم الهواتف مع تقليل الحركة عند تفعيل إعدادات تقليل الحركة.
- لم يتم تغيير قاعدة البيانات أو منطق API.

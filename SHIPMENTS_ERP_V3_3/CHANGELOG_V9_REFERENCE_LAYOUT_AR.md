# V9 — إعادة بناء تخطيط مطابق للمرجع

- إصلاح شريط التنقل الأفقي في الهاتف: استبداله بقائمة جانبية قابلة للفتح والإغلاق، وإزالة شريط التمرير الأفقي الذي ظهر كسهم/خط رمادي.
- الإبقاء على القائمة الجانبية الكاملة في الشاشات الكبيرة.
- إضافة مساحة عمل تنفيذية للصفحة الرئيسية تضم مخطط اتجاه، مؤشر حالة دائري، مقارنة أداء الفروع، وروابط وصول سريع.
- تحسين شبكة مؤشرات الأداء لتظهر في عمودين على الهاتف بدل التكدس الرأسي.
- توحيد طبقات الإضاءة والحدود المتوهجة مع الطابع الكحلي/الأزرق المرجعي.
- الصفحات الداخلية تظل مستقلة عبر التنقل، ولا يتم تغيير قاعدة البيانات أو منطق العمليات.
- رسوم لوحة النظرة التنفيذية أرقام/مؤشرات توضيحية للعرض وليست بيانات إنتاجية.
